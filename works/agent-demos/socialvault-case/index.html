01

缘起 Why

Bookmarks rot. Archives live.

我的灵感散落在十几个平台：X 上的排版参考、小红书的家装图、B 站的讲座、公众号的长文。各平台自带的「收藏」是黑洞——收进去，就再也不会被想起，平台一改版还可能整批消失。

于是有了 Archive Of My Own：一个只听命于我的收藏库。数据是本目录下一个 data.json，服务是一个不依赖任何 npm 包的 server.js——Node 内置的 http、fetch、crypto 就足够。可以随时备份、随时搬走，像一只能带走的铁皮盒子。

「收藏不是终点。被重新遇见，才是。」

随机重温 Rediscovery

Interactive · 从库存随机抽 5 条，进入专注模式

每周一次的仪式：点下「随机重温」，系统抽出 5 条未归档收藏，全屏逐条过一遍。还心动的留下，已经无感的归档。收藏库因此永远保持「现在的我也喜欢」。

04

架构 Anatomy

One server.js, zero packages
Server
server.js · ~600 行
静态服务 + JSON API + og 抓取 + 视频字幕提取 + 图片代理 + CORS，全部只用 http/fs/crypto/fetch。首次启动自动播种示例数据。
Capture
OG 抓取 + 图片代理
og:image 相对路径补全；封面经 /api/image-proxy 带目标站 Referer 转发，绕开防盗链，内存缓存 30 分钟。
Extension
Chrome MV3 扩展
登录墙平台抓不到 meta？扩展直接读当前页 DOM 提取标题封面；右键菜单一键收藏页面或链接。
Reflection
反思页 + 重温
YouTube 字幕提取一键存为反思；随机重温、归档、标签多选筛选、会话内稳定的随机排序。

/api/posts
