A NOTE ON ATTENTION / 01

Look once.
Look again.

我们把网页做得越来越快，却很少讨论“看过之后”发生了什么。Afterimage 把浏览变成一段有回声的阅读：你的注意力越久，页面越偏离最初的样子。

“A page is
never still.”

Every scroll leaves a faint mark. The longer you stay, the more the typography loosens, the more the color warms, the more the machine admits it was watching too.
